# 主体消歧要点

品牌「字节跳动」≠ 必然签约主体。2022 年 5 月前后集团内多家公司更名：
- 字节跳动（香港）有限公司 → 抖音集团（香港）有限公司（2022-05-06 生效，媒体口径）
- 字节跳动有限公司 → 抖音有限公司 / 抖音集团（商业名称）
- 北京字节跳动科技有限公司 → 北京抖音信息服务有限公司

后端研发岗实际签约主体还可能按城市/业务使用不同子公司（如上海字跳网络技术有限公司等，本次未核实），必须以 Offer 与合同抬头为准。
